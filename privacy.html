Privacy Policy

Last updated: October 22, 2026

Job Search Copilot is a personal tool used by one person, its owner. This policy explains how it handles data, including data from Google APIs.

Who can use it

Only the owner can sign in. The app does not offer accounts to anyone else.

Google user data the app accesses

With the owner's permission, the app uses the Gmail API to:

  • Read email messages to find job alerts and career-related messages such as recruiter outreach, application confirmations and interview requests (gmail.readonly).
  • Create draft replies that the owner reviews and sends himself (gmail.compose). The app does not send email on its own.

How the data is used

Email content is used only to identify job opportunities and career updates, update the owner's private application tracker, and prepare drafts for the owner. Relevant email text may be sent to an AI model provider (Anthropic) for classification and summarization, under that provider's commercial API terms.

Storage and security

Extracted job and application data is stored in a private, access-controlled database used only by the owner. Access credentials are kept in protected server settings and are never published.

Sharing

The app does not sell, rent or share Google user data with anyone, does not use it for advertising, and does not use it to train AI models.

Limited Use

Job Search Copilot's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Deleting data and revoking access

The owner can delete all stored data at any time and can revoke the app's Gmail access at myaccount.google.com/permissions.
